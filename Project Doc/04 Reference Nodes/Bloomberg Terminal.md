# Bloomberg Terminal

## Role in this vault

Bloomberg describes the Terminal as a professional workflow combining market data, news, research, analytics, collaboration, and execution-related tools across asset classes.

## Mechanics and design considerations

For system design, distinguish a human desktop workflow from licensed enterprise feeds/APIs; entitlement, redistribution rights, timestamping, and fallback-data policy are design constraints.
