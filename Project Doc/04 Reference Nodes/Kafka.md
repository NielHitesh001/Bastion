# Kafka

## Role in this vault

Apache Kafka is a distributed event-streaming platform. In a trading/risk architecture it can carry market data, trade events, and calculation events between independently deployed services.

## Mechanics and design considerations

Partition-key selection, ordering guarantees, retention, schema evolution, replay, deduplication, and consumer lag are operational parameters—not optional implementation details.
