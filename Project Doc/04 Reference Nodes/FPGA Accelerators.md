# FPGA Accelerators

## Role in this vault

Field-programmable gate arrays can implement specialized low-latency logic in reconfigurable hardware. The supplied notes use them as a latency-critical execution concept.

## Mechanics and design considerations

Use only where measurement justifies complexity: define clocking, market-data normalization, deterministic risk gates, rollout/rollback, simulation, and observability before moving logic into hardware.
