# OCaml

## Role in this vault

OCaml is a statically typed functional programming language with a strong type system and a mature compiler/tooling ecosystem.

## Mechanics and design considerations

For risk and pricing code, algebraic data types can make instrument and state variants explicit; performance-sensitive paths still require profiling, allocation awareness, and careful boundary design.
