# ION Trading

## Role in this vault

ION describes FX trading/execution tooling with liquidity aggregation, smart-order routing, execution algorithms, and benchmarking.

## Mechanics and design considerations

A routing integration needs explicit controls for venue eligibility, pre-trade risk, throttles, kill switches, reject handling, and post-trade reconciliation.
